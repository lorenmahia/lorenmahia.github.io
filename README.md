# lorenmahia.github.io

Personal site of Loren Mburu Mahia, software engineer working on camera platforms and AI-driven test tooling.

Live at **https://lorenmahia.github.io**

## About

A single `index.html` styled like a camera viewfinder: corner brackets, readouts, a focus ring that follows the cursor, and detection boxes on projects. Plain HTML, CSS and JavaScript, with no framework or build step.

## Run locally

```sh
python -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

GitHub Pages serves the `main` branch from the repository root. Push to `main` and the site updates within a minute or two.
